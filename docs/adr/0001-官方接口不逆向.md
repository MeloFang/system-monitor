# ADR-0001：数据与控制走华硕官方驱动接口，不逆向 Armoury Crate

- 状态：已决定（2026-10-25）
- 背景：要把 AC 的「系统使用率 + 操作模式」抽成独立软件，数据获取有三条路：自采（LHM/NVML/WMI）、读 AC 内部（插件总线/内存/配置）、逆向 AC。
- 决策：采集走 LibreHardwareMonitor + NVML；模式读写走华硕 ASUS System Control Interface（ACPI WMI）官方驱动接口。**禁止**任何针对 Armoury Crate 进程、内存、named pipe、配置文件的读写与修改。
- 理由：
  1. AC 插件总线无公开 schema，华硕一次版本更新即静默失效，维护成本不可控
  2. 逆向/修改官方软件违反 EULA，且可能触发驱动校验
  3. 官方 WMI 接口已被 G-Helper 在目标机型上完整验证，能力集与 AC 一致
- 代价：风扇等数据的可读性依赖机型固件（用探针先行验证）；与 AC 并存时控制权冲突需用户二选一。
